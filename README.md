# CSS Grid: `grid-row`

Lưới 3 cột minh họa cách một item chiếm hai hàng bằng `grid-row`.

## Chạy thử

Mở `index.html` trong trình duyệt rồi chọn ba nút phía trên lưới:

- `1 / 3`: item chiếm hai hàng, bắt đầu ở hàng đầu.
- `2 / 4`: item chiếm hai hàng, bắt đầu ở hàng thứ hai.
- `span 2`: item trải qua hai hàng tại vị trí tự động.

Mã CSS và phần giải thích cập nhật khi đổi lựa chọn.
